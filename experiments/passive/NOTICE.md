# Quoted style guide text

`rules.json`, the rubrics under `microsoft/` and `redhat/`, and
`../voice-calibration.json` quote short passages and example sentences from
published style guides, so readers can check each rubric against the rule it
encodes. This repository's MIT license doesn't cover the quoted text. Each source
keeps its own license:

| Source | License | Where the quoted text comes from |
|---|---|---|
| [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/grammar/verbs) | [CC BY 4.0](https://github.com/MicrosoftDocs/microsoft-style-guide/blob/main/LICENSE) | `styleguide/grammar/verbs.md` in [MicrosoftDocs/microsoft-style-guide](https://github.com/MicrosoftDocs/microsoft-style-guide) |
| [Vale at Red Hat](https://redhat-documentation.github.io/vale-at-red-hat/), PassiveVoice rule | [MIT](https://github.com/redhat-documentation/vale-at-red-hat/blob/main/LICENSE) | `docs/modules/passivevoice.adoc` in [redhat-documentation/vale-at-red-hat](https://github.com/redhat-documentation/vale-at-red-hat). Its summary of IBM Style's exceptions is quoted from that page, not from IBM Style itself |
| [Red Hat supplementary style guide](https://redhat-documentation.github.io/supplementary-style-guide/) | [CC BY-SA 4.0](https://github.com/redhat-documentation/supplementary-style-guide/blob/main/LICENSE) | The prerequisites guidance. Text quoted from it stays under CC BY-SA 4.0 |
| [Google developer documentation style guide](https://developers.google.com/style/voice) and [Technical Writing One](https://developers.google.com/tech-writing/one) | [CC BY 4.0](https://developers.google.com/site-policies) | Example sentences in `../voice-calibration.json` |
| [Kubernetes documentation style guide](https://kubernetes.io/docs/contribute/style/style-guide/) | [CC BY 4.0](https://github.com/kubernetes/website/blob/main/LICENSE) | Example sentences in `../voice-calibration.json` |

The published pages may have changed since the text was copied.
